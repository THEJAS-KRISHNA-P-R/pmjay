# `/privacy` — Privacy Policy

## Purpose
Public-facing disclosure of PMJAY Advocate's privacy guarantees and data handling practices, structured to comply with India's Digital Personal Data Protection Act (DPDP Act 2023).

## Key Architecture Guarantees Documented
1. **Zero User Accounts**: No phone numbers, emails, or Aadhaar credentials are required or stored centrally.
2. **Local-First History**: Cases and preferences are retained in `localStorage` in the user's browser, reachable only by unguessable UUIDv4 links.
3. **Ephemeral AI Evaluation**: Medical situation narratives are evaluated on enterprise API tiers with zero retention for model training.
4. **No Third-Party Advertising/Tracking**: Zero tracking pixels or marketing analytics cookies.
